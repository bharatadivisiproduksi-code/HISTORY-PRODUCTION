Koneksi Spreadsheet

Sambungkan aplikasi ini ke Google Sheets, atau impor/ekspor file Excel.

1) Google Sheets

Langkah: buat Google Sheet kosong → Extensions → Apps Script → tempel kode di bawah → Deploy → Web app (Who has access: Anyone) → salin URL.

Belum terhubung.


2) File Excel
Impor file .xlsx (kolom sama seperti hasil ekspor). Data lama akan diganti.
Data tersimpan otomatis di browser Anda. Gunakan Google Sheets atau Excel untuk cadangan / berbagi tim.



Panduan Singkat
Dashboard – angka ringkas, grafik bulanan, produk teratas, achievement, waste.
Data Produksi – cari, filter, urutkan, tambah (＋), ubah (✎), hapus (🗑).
Achievement = Masuk Gudang ÷ Target hasil jadi. ≥100% 95–99% <95%
Hasil Produksi = Masuk Gudang (Shift 1+2+3). Pertinggal (sampel) dicatat terpisah dan TIDAK dijumlahkan. Angka ini sama dengan sheet REKAP (1.671.329 pcs).
Master Produk – daftar produk + SKU. Tambah produk baru manual (nama & SKU), ubah, atau hapus (jika belum dipakai). Saat input batch, SKU otomatis terisi.
Spreadsheet – hubungkan ke Google Sheets (tarik/kirim) atau impor/ekspor Excel.
